sin ventana cinematográfica. **La aplicación aislada aún no está implementada:**
esta sesión cambia el plan y conserva las entregas existentes.

- [Estado y siguiente trabajo](docs/estado.md).
- [Plan canónico en Blender](../../blender/chupacabras/docs/plan_secuencia.md).
- [Preparación de la migración](docs/figura_ar.md).

Abrir este proyecto solo con Unity **6000.3.22f1** instalado en
`/home/cacawatin/Unity/Hub/Editor/6000.3.22f1/Editor/Unity`.
Desarrollo y compilación Android desde Linux; no cambiar Editor ni detector.

La escena existente `Assets/Scenes/12_AppearanceAR_demacrado_r02.unity`
muestra el modelo inicial y el panel histórico. La nueva escena de figura se
creará en F1. Las escenas `13_calma_r07.unity` y `14_ataque_r07.unity` son
muestras históricas de actuación; sus fuentes están en el repositorio Blender.
Los archivos anteriores se conservan; no usar sus guías como próximos pasos.
